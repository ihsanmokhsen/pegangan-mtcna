Module 1Introduction
Objective
  • About MikroTik

    MikroTik adalah perusahaan asal Latvia (berdiri 1996) yang membuat perangkat lunak dan perangkat keras jaringan: router, switch, dan perangkat wireless. Produknya populer di ISP, WISP, dan kantor karena murah tetapi fiturnya lengkap.

    • What is RouterOS
      Istilah: Sistem operasi = software utama yang menjalankan perangkat (seperti Windows di laptop).

      RouterOS adalah sistem operasi (software) buatan MikroTik, berbasis Linux. Fiturnya: routing, firewall, NAT, DHCP, bridge, wireless, VPN, hotspot, queue/bandwidth, dan monitoring. Bisa berjalan di RouterBOARD, PC biasa (x86), maupun mesin virtual (CHR = Cloud Hosted Router).

    • What is RouterBOARD

      RouterBOARD (RB) adalah perangkat keras (hardware) buatan MikroTik yang sudah terpasang RouterOS beserta lisensinya. Contoh: hEX, hAP, RB750, CCR, CRS. Ringkasnya: RouterOS = software, RouterBOARD = hardware.

  • First time accessing the router ★ WAJIB

    Cara masuk pertama kali ke router baru. Default yang umum: IP 192.168.88.1, user admin. Perangkat lama tanpa password; perangkat baru memakai password yang tertera di stiker.

    • WinBox and MAC-WinBox
      Istilah: GUI = tampilan berupa jendela & tombol; MAC address = alamat fisik kartu jaringan.

      WinBox adalah aplikasi GUI resmi untuk mengatur router (port TCP 8291). Bisa terhubung lewat IP, atau lewat MAC address (MAC-WinBox). MAC-WinBox bekerja di Layer 2 sehingga tetap bisa masuk walau router belum punya IP atau IP-nya salah, asal laptop terhubung di segmen jaringan yang sama. Tab "Neighbors" di WinBox menampilkan router MikroTik di sekitar.

    • WebFig and Quick Set

      WebFig = pengaturan router lewat browser (ketik IP router, port 80/443). Quick Set = halaman wizard sederhana untuk skenario umum (Home AP, CPE, PTP Bridge, dll.): cukup isi IP WAN/LAN, Wi-Fi, dan password, router langsung jalan.

    • Default configuration

      Konfigurasi bawaan pabrik yang berbeda per model. Umumnya pada router rumahan: ether1 = WAN (DHCP client), port lain digabung dalam bridge sebagai LAN dengan IP 192.168.88.1/24, DHCP server aktif, NAT masquerade, dan firewall dasar. Saat login pertama, WinBox bisa menawarkan untuk menghapusnya ("Remove Configuration"). Lihat isinya: /system default-configuration print.

  • RouterOS command line interface (CLI)
    Istilah: CLI = mengatur router dengan mengetik perintah, bukan klik.

    Semua yang bisa dilakukan di WinBox juga bisa lewat CLI. CLI lebih cepat untuk banyak perintah sekaligus dan dipakai untuk script.

    • Null Modem cable

      Kabel serial (RS-232) yang menyilangkan jalur kirim-terima, untuk akses console langsung ke router yang punya port serial (mis. CCR, RB1100). Berguna saat semua akses jaringan gagal. Setting umum: 115200 bps, 8N1.

    • SSH and Telnet

      Akses CLI jarak jauh lewat jaringan. SSH (port 22) terenkripsi, aman. Telnet (port 23) tidak terenkripsi, password bisa disadap; sebaiknya dimatikan. Dari laptop: ssh admin@192.168.88.1.

    • New terminal in WinBox/WebFig

      Tombol New Terminal di menu kiri WinBox/WebFig membuka jendela CLI tanpa perlu aplikasi SSH.

  • RouterOS CLI principles

    Menu CLI tersusun bertingkat seperti folder, sama dengan susunan menu di WinBox. Contoh: /ip address = menu IP › Addresses.

    • <tab>, double <tab>, "?", navigation

      Tab = melengkapi perintah; Tab Tab = menampilkan semua pilihan; ? = bantuan/penjelasan perintah. Navigasi: / = ke menu paling atas, .. = naik satu tingkat, ketik nama menu untuk masuk. Perintah umum: print, add, set, remove, enable, disable. Ctrl+X = Safe Mode.

    • Command history and its benefits

      Tombol panah atas/bawah memanggil perintah yang pernah diketik, sehingga tidak perlu mengetik ulang dan mengurangi salah ketik. Riwayat perubahan konfigurasi juga bisa dilihat dan dibatalkan dengan /system history print dan /undo.

  • Initial configuration (Internet access) ★ WAJIB

    Tiga langkah agar PC di LAN bisa internet: WAN dapat IP, LAN punya gateway, dan NAT. PC juga butuh IP (dari DHCP server atau manual) dan DNS.

    /ip dhcp-client add interface=ether1 disabled=no
/ip address add address=192.168.10.1/24 interface=ether2
/ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
/ip dns set servers=8.8.8.8 allow-remote-requests=yes
    • WAN DHCP-client
      Istilah: WAN = sisi yang menghadap ISP/internet; DHCP client = meminta IP otomatis.

      Interface WAN (biasanya ether1) meminta IP, gateway, dan DNS otomatis dari modem/ISP. Opsi add-default-route=yes membuat default route otomatis (muncul sebagai rute dinamis). Jika ISP memakai PPPoE atau IP statis, caranya berbeda.

    • LAN IP address and default gateway
      Istilah: Default gateway = pintu keluar menuju jaringan lain.

      Pasang IP di interface LAN, contoh 192.168.10.1/24. IP ini menjadi default gateway bagi PC. Router sendiri juga butuh default gateway ke ISP (rute 0.0.0.0/0), yang biasanya didapat dari DHCP client.

    • Basic Firewall - NAT masquerade
      Istilah: NAT = Network Address Translation, menerjemahkan alamat IP.

      IP privat (192.168.x.x) tidak bisa dipakai di internet. Masquerade mengganti IP pengirim dari PC dengan IP WAN router saat paket keluar, sehingga banyak PC berbagi satu IP publik. Rule: chain=srcnat out-interface=ether1 action=masquerade.

  • Upgrading RouterOS

    Upgrade memperbaiki bug, menutup celah keamanan, dan menambah fitur. Sebelum upgrade: buat backup, baca changelog. Cek versi: /system resource print.

    • Package types
      Istilah: Package (.npk) = file paket instalasi RouterOS; arsitektur = jenis prosesor (arm, arm64, mipsbe, mmips, smips, tile, x86).

      Ada main package (routeros-<arsitektur>-<versi>.npk) berisi fitur inti, dan extra packages untuk fitur tambahan (mis. wireless, user-manager, ntp, iot). File paket harus sesuai arsitektur prosesor router. Lihat paket terpasang: /system package print.

    • Ways of upgrading

      (1) System › Packages › Check For Updates: pilih channel (long-term, stable, testing, development) lalu Download & Install. (2) Upload file .npk ke menu Files (drag-drop di WinBox atau FTP), lalu reboot. (3) Netinstall. (4) Otomatis dari The Dude untuk banyak router. Downgrade: upload versi lama lalu /system package downgrade.

    • RouterBOOT firmware upgrade
      Istilah: RouterBOOT = firmware/bootloader (seperti BIOS) yang menyalakan perangkat sebelum RouterOS jalan.

      Upgrade RouterOS tidak otomatis meng-upgrade RouterBOOT. Setelah upgrade RouterOS, cek /system routerboard print (current vs upgrade firmware), jalankan /system routerboard upgrade, lalu reboot.

  • Router identity

    Nama router, tampil di prompt CLI, judul WinBox, dan daftar Neighbors. Memudahkan membedakan banyak router. /system identity set name=RTR-KANTOR.

  • Manage RouterOS logins

    Mengatur akun di /user. Grup bawaan: full (semua hak), write (ubah config, tanpa kelola user), read (hanya lihat). Bisa buat grup sendiri dengan policy tertentu, dan batasi login dari IP tertentu (address/allowed-address). Ganti/hapus akun admin bawaan dan pakai password kuat. Lihat user yang sedang login: /user active print.

    /user add name=operator group=read password=PasswordKuat123
  • Manage RouterOS services

    Layanan akses ke router ada di /ip service: telnet (23), ftp (21), www (80), ssh (22), www-ssl (443), api (8728), api-ssl (8729), winbox (8291). Matikan yang tidak dipakai, ubah port bila perlu, dan isi available from agar hanya IP admin yang bisa akses.

    /ip service disable telnet,ftp,www,api
/ip service set winbox address=192.168.10.0/24
  • Managing configuration backups ★ WAJIB

    Simpan konfigurasi sebelum perubahan besar. Simpan juga salinannya di luar router (unduh dari menu Files), karena file di router hilang jika di-Netinstall.

    • Saving and restoring the backup

      Simpan: /system backup save name=kantor → file kantor.backup. Pulihkan: /system backup load name=kantor.backup lalu router reboot. Backup bisa diberi password/enkripsi.

    • Difference between a backup and an export (.rsc) file

      Backup (.backup) = file biner, tidak bisa dibaca, memuat seluruh config termasuk user & password, ditujukan untuk dipulihkan ke router yang sama (atau model yang sama). Export (.rsc) = file teks berisi perintah CLI, bisa dibaca dan diedit, bisa dipakai sebagian atau ke router lain; tidak memuat password user. Buat: /export file=kantor. Pulihkan: /import file-name=kantor.rsc.

    • Editing an export file

      Karena berupa teks, file .rsc bisa dibuka dengan Notepad/TextEdit: ubah IP, nama interface, atau hapus bagian yang tidak perlu, lalu upload dan /import. Bisa juga copy-paste isinya ke Terminal. Cocok untuk membuat template konfigurasi.

  • Resetting a RouterOS device

    Mengembalikan konfigurasi ke default atau kosong. Lewat CLI: /system reset-configuration (opsi: no-defaults=yes = benar-benar kosong, keep-users=yes, skip-backup=yes). Lewat tombol fisik: tahan tombol reset saat menyalakan router hingga LED berkedip, lalu lepas. Reset hanya menghapus konfigurasi, bukan instal ulang RouterOS.

  • Reinstalling a RouterOS device (Netinstall)
    Istilah: Netinstall = program dari MikroTik (Windows, ada versi CLI Linux) untuk memasang ulang RouterOS lewat kabel jaringan.

    Dipakai saat router rusak sistemnya, lupa password, atau mau mulai benar-benar bersih. Langkah: PC diberi IP statis, jalankan Netinstall, router di-boot dari jaringan (tahan tombol reset ±15 detik sampai muncul di Netinstall, atau set boot-device try-ethernet-once-then-nand), pilih file .npk, klik Install. Semua konfigurasi terhapus, tetapi lisensi tetap.

  • RouterOS license levels ★ WAJIB

    Level lisensi menentukan fitur/kapasitas. RouterBOARD sudah membawa lisensi sesuai modelnya dan lisensi tidak bisa dipindah ke perangkat lain.

    Level 0 trial 24 jam (x86) · Level 1 demo gratis, fitur sangat terbatas · Level 3 = CPE, wireless hanya sebagai station (tidak bisa AP) · Level 4 = bisa jadi wireless Access Point (WISP) · Level 5 seperti 4 dengan kapasitas tunnel/hotspot lebih besar · Level 6 controller, tanpa batas. CHR (virtual) memakai skema lain: free, p1, p10, p-unlimited. Cek: /system license print.

Module 2DHCP
Objective
  • DHCP server and client ★ WAJIB
    Istilah: DHCP = Dynamic Host Configuration Protocol, pembagi IP otomatis (port UDP 67/68).

    DHCP memberikan IP, subnet mask, gateway, dan DNS ke perangkat secara otomatis. Prosesnya disebut DORA: Discover → Offer → Request → Acknowledge. Router bisa sekaligus menjadi DHCP client (di WAN) dan DHCP server (di LAN).

    • DHCP client

      Interface yang meminta IP dari server DHCP lain (modem/ISP). /ip dhcp-client add interface=ether1 disabled=no. Opsi penting: use-peer-dns (pakai DNS dari ISP), add-default-route. Status harus bound jika berhasil.

    • DHCP server setup

      Cara termudah: wizard /ip dhcp-server setup (atau tombol DHCP Setup di WinBox), lalu jawab pertanyaan: interface, network, gateway, pool, DNS, lease time. Interface harus sudah punya IP sebelum DHCP server dibuat. Secara manual ada 3 bagian: IP pool, DHCP server, DHCP network.

      /ip pool add name=pool-lan ranges=192.168.10.10-192.168.10.254
/ip dhcp-server add name=dhcp-lan interface=ether2 address-pool=pool-lan disabled=no
    • Leases management
      Istilah: Lease = "sewa" IP ke satu perangkat untuk jangka waktu tertentu (lease time).

      Daftar perangkat yang mendapat IP ada di /ip dhcp-server lease print. Lease dynamic (flag D) dibagi otomatis; tombol Make Static mengubahnya menjadi static lease: IP selalu sama untuk MAC address itu (cocok untuk printer/server). Lease juga bisa diblokir atau diberi rate-limit.

    • DHCP server network configuration

      Bagian /ip dhcp-server network menentukan apa yang dikirim ke client: network address, gateway, dns-server, domain, NTP. Jika gateway/DNS salah, client dapat IP tetapi tidak bisa internet.

      /ip dhcp-server network add address=192.168.10.0/24 gateway=192.168.10.1 dns-server=8.8.8.8
  • Address Resolution Protocol (ARP)
    Istilah: ARP = protokol yang mencari MAC address dari sebuah IP di jaringan lokal.

    Sebelum mengirim paket ke 192.168.10.5, perangkat bertanya ke seluruh LAN (broadcast): "Siapa pemilik 192.168.10.5?" Pemiliknya menjawab dengan MAC address-nya. Hasilnya disimpan di ARP table.

    • ARP modes

      Diatur per interface: enabled (default, normal) · disabled (tidak memakai ARP; hanya entri statis) · reply-only: hanya menjawab perangkat yang terdaftar statis di ARP table, dipakai untuk mengunci jaringan, sering dipadukan dengan opsi DHCP server add-arp=yes · proxy-arp: router menjawab ARP atas nama perangkat di jaringan lain · local-proxy-arp.

    • RouterOS ARP table

      Lihat di /ip arp print: pasangan IP – MAC – interface. Entri dinamis (D) bisa dijadikan statis (Make Static) atau ditambah manual: /ip arp add address=192.168.10.5 mac-address=AA:BB:CC:DD:EE:FF interface=ether2.

    Praktik: DHCP client di WAN, DHCP server di LAN, melihat & menjadikan lease statis, mengubah DNS/gateway di DHCP network, melihat ARP table, dan mencoba mode reply-only.

Module 3Bridging
Objective
  • Bridging overview
    Istilah: Bridge = penggabung beberapa interface menjadi satu jaringan Layer 2, seperti switch.

    Perangkat yang tersambung ke port-port dalam satu bridge berada di jaringan (broadcast domain) yang sama dan bisa saling berkomunikasi seolah tersambung ke satu switch. Bridge bekerja di Layer 2 (MAC address).

    • Bridge concepts and settings
      Istilah: Loop = kabel membentuk lingkaran sehingga paket berputar tanpa henti (broadcast storm); STP/RSTP = Spanning Tree Protocol, pencegah loop.

      Bridge mempelajari MAC address di tiap port (host table) lalu meneruskan frame ke port yang tepat. Setting penting: protocol-mode = none / stp / rstp (default) untuk mencegah loop, MAC address bridge, ARP mode, dan (di versi baru) hardware offload agar diproses chip switch.

    • Creating bridges

      Bridge adalah interface virtual: /interface bridge add name=bridge-lan. Setelah dibuat, ia muncul di daftar interface dan bisa diberi IP.

    • Adding ports to bridges

      Masukkan port fisik/wireless sebagai anggota: /interface bridge port add bridge=bridge-lan interface=ether2 (ulangi untuk ether3, wlan1, dst.). IP address dan DHCP server dipasang di interface bridge, bukan di port anggotanya.

      /ip address add address=192.168.10.1/24 interface=bridge-lan
  • Bridge wireless networks

    Port wireless (wlan1) bisa dimasukkan ke bridge yang sama dengan port kabel, sehingga perangkat Wi-Fi dan kabel berada dalam satu jaringan dan satu DHCP server.

    • Station bridge
      Istilah: Station = mode client wireless yang menyambung ke AP.

      Mode station biasa tidak bisa di-bridge (standar 802.11 hanya mengizinkan satu MAC dari station). station-bridge = mode khusus MikroTik ke MikroTik (AP harus ap-bridge/bridge) yang memungkinkan bridging penuh di sisi station, misalnya menyambung LAN dua gedung. Alternatif untuk AP merek lain: station-pseudobridge atau station-wds.

  • Module 3 laboratory

    Praktik: membuat bridge, memasukkan port ether dan wlan, memindahkan IP & DHCP server ke bridge, lalu menguji komunikasi antar-client; membuat link wireless station-bridge.

Module 4Routing
Objective
  • Routing overview
    Istilah: Routing = menentukan jalur paket dari satu jaringan ke jaringan lain (Layer 3, berdasarkan IP).

    Router menyimpan peta jalan di routing table (/ip route print): tujuan (dst-address) dan lewat mana (gateway).

    • Routing concepts
      Istilah: Gateway/next hop = router berikutnya; distance = prioritas rute (kecil = diutamakan).

      Router memilih rute dengan aturan: (1) yang paling spesifik (prefix terbesar) menang; (2) jika prefix sama, distance terkecil menang. Distance bawaan: connected = 0, static = 1, DHCP = 1, OSPF = 110. Gateway harus berada di jaringan yang terhubung langsung, kalau tidak rute menjadi tidak aktif. Rute harus ada di kedua arah agar balasan bisa pulang.

    • Route flags

      Huruf di depan setiap rute: X disabled · A active · D dynamic · C connected · S static · r rip · b bgp · o ospf · m mme · B blackhole · U unreachable · P prohibit. Contoh: DAC = dynamic active connected (muncul otomatis saat IP dipasang); AS = active static; DAd (v7) = dari DHCP.

  • Static routing
    Istilah: Static route = rute yang ditulis manual oleh admin.

    Cocok untuk jaringan kecil dan sederhana. Kekurangannya: tidak menyesuaikan otomatis jika ada link putus.

    • Creating routes

      /ip route add dst-address=192.168.20.0/24 gateway=10.0.0.2 artinya: "untuk ke 192.168.20.0/24, kirim lewat 10.0.0.2". Opsional: distance, comment, check-gateway=ping (cek gateway hidup).

    • Setting default route

      Default route = dst-address=0.0.0.0/0, dipakai untuk semua tujuan yang tidak punya rute lebih spesifik (biasanya internet). /ip route add dst-address=0.0.0.0/0 gateway=192.168.1.1. Dua default route dengan distance berbeda = failover sederhana.

    • Managing dynamic routes
      Istilah: Dynamic route = rute yang muncul otomatis (flag D).

      Sumbernya: IP yang dipasang di interface (connected), DHCP client (add-default-route), koneksi PPP/PPPoE, atau protokol routing (OSPF/BGP). Rute dinamis tidak bisa diedit langsung; ubah dari sumbernya, misal default-route-distance di DHCP client.

    • Implementing static routing in a simple network

      Contoh 2 router: A (LAN 192.168.10.0/24, transit 10.0.0.1/30) dan B (LAN 192.168.20.0/24, transit 10.0.0.2/30).

      # di Router A
/ip route add dst-address=192.168.20.0/24 gateway=10.0.0.2
# di Router B
/ip route add dst-address=192.168.10.0/24 gateway=10.0.0.1

      Uji dengan ping antar-LAN dan traceroute. Pastikan PC memakai gateway yang benar dan tidak ada NAT/firewall yang memblokir.

  • Module 4 laboratory

    Praktik: membaca routing table & flag, membuat default route, membuat static route antar router peserta, dan menguji dengan ping/traceroute.

Module 5Wireless
Objective
  • 802.11a/b/g/n/ac Concepts ★ WAJIB
    Istilah: 802.11 = keluarga standar Wi-Fi dari IEEE.

    802.11b 2.4 GHz, 11 Mbps · 802.11a 5 GHz, 54 Mbps · 802.11g 2.4 GHz, 54 Mbps · 802.11n 2.4 & 5 GHz, MIMO, ±150 Mbps per chain · 802.11ac hanya 5 GHz, hingga Gigabit. Di MikroTik dipilih lewat band, mis. 2ghz-b/g/n atau 5ghz-a/n/ac.

    • Frequencies (bands, channels) data-rates / chains (tx power, rx sensitivity, country regulations)
      Istilah: Band = rentang frekuensi; channel = lajur dalam band; chain = jalur radio/antena (MIMO); dBm = satuan kekuatan sinyal.

      Band & channel: 2.4 GHz punya channel 1–13 dengan lebar 20 MHz; yang tidak saling tumpang tindih: 1, 6, 11. 5 GHz punya lebih banyak channel dan interferensi lebih sedikit, tapi jangkauan lebih pendek.

      Data rate: kecepatan modulasi; makin jauh/lemah sinyal makin turun. Kecepatan nyata ±50–60% dari data rate.

      Chains: 802.11n/ac memakai beberapa chain (2×2, 3×3) untuk menaikkan kecepatan.

      TX power = daya pancar; RX sensitivity = kemampuan menangkap sinyal lemah. Sinyal −50 dBm sangat baik, −70 cukup, −85 buruk. TX power tinggi tidak otomatis bagus: client juga harus bisa membalas.

      Country regulations: setting country=indonesia membatasi channel & daya sesuai aturan negara; frequency-mode=regulatory-domain.

  • Setup a simple wireless link

    Link sederhana = satu AP dan satu station dengan SSID, band, dan pengamanan yang sama.

    • Access Point configuration
      Istilah: SSID = nama jaringan Wi-Fi.

      Mode ap-bridge (banyak client, butuh lisensi level 4) atau bridge (hanya 1 client, level 3). Atur SSID, band, channel/frequency, country, dan security profile.

      /interface wireless set wlan1 mode=ap-bridge ssid=KANTOR band=2ghz-b/g/n \
    frequency=2437 country=indonesia security-profile=wpa2 disabled=no
    • Station configuration

      Mode station (atau station-bridge jika perlu bridging), SSID dan security profile sama dengan AP. Tombol Scan menampilkan AP di sekitar untuk dipilih. Status sukses: connected to ess.

  • Wireless Security and Encryption

    Melindungi Wi-Fi dari pengguna tak berhak dan penyadapan. Penyaringan MAC saja tidak cukup karena MAC bisa dipalsukan; tetap gunakan enkripsi WPA2.

    • Access List

      Dipakai di AP: daftar client (berdasarkan MAC) yang diizinkan atau ditolak terhubung, bisa juga dengan syarat kekuatan sinyal, waktu, atau key khusus. Dibaca dari atas ke bawah.

    • Connect List

      Dipakai di station: daftar AP (MAC/SSID) yang boleh atau tidak boleh dihubungi station, beserta prioritasnya.

    • Default Authenticate

      Centang (default) = client yang tidak ada di Access List tetap boleh terhubung. Tidak dicentang = hanya client yang ada di Access List yang bisa terhubung (whitelist). Untuk station, opsi ini berlaku terhadap Connect List.

    • Default Forward

      Centang (default) = sesama client di AP yang sama bisa saling berkomunikasi. Tidak dicentang = client isolation, sesama client tidak bisa saling akses; cocok untuk Wi-Fi tamu/hotspot.

    • WPA-PSK, WPA2-PSK
      Istilah: PSK = Pre-Shared Key, satu kata sandi bersama; AES/CCMP = metode enkripsi kuat; TKIP = metode lama.

      Diatur di Security Profiles: mode dynamic-keys, authentication WPA2-PSK, cipher aes-ccm, isi password (minimal 8 karakter). WPA-PSK (TKIP) dan WEP sudah tidak aman.

      /interface wireless security-profiles add name=wpa2 mode=dynamic-keys \
    authentication-types=wpa2-psk unicast-ciphers=aes-ccm group-ciphers=aes-ccm \
    wpa2-pre-shared-key=PasswordWiFiKuat
    • WPS accept, WPS client
      Istilah: WPS = Wi-Fi Protected Setup, sambung tanpa mengetik password.

      WPS accept (di AP): membuka jendela waktu singkat (±2 menit) agar perangkat bisa bergabung dengan menekan tombol WPS. WPS client (di station): station meminta kunci dari AP lewat WPS. Matikan WPS jika tidak diperlukan.

  • Monitoring Tools

    Alat untuk melihat kondisi Wi-Fi dan sekitarnya.

    • Snooper

      Memindai seluruh channel di band yang dipilih dan menampilkan jaringan, perangkat, serta tingkat pemakaian tiap frekuensi. Dipakai untuk memilih channel yang paling sepi. Interface wireless berhenti melayani client selama snooper berjalan. Alat sejenis: Scan, Frequency Usage.

    • Registration table

      Daftar client yang sedang terhubung ke AP (atau AP yang dihubungi station): MAC, sinyal (dBm), signal-to-noise, TX/RX rate, uptime. Tombol Copy to Access List memudahkan whitelist. /interface wireless registration-table print.

  • Module 5 laboratory

    Praktik: membuat AP dan station, security profile WPA2, mengatur access list/connect list, default authenticate/forward, memakai snooper dan registration table.

Module 6Firewall
Objective · bobot soal terbesar
  • Firewall principles ★ WAJIB
    Istilah: Firewall = "satpam" yang memeriksa paket dan memutuskan diizinkan atau dibuang; rule = satu aturan (syarat + tindakan).

    Firewall di RouterOS ada di /ip firewall: filter (izinkan/blokir), nat (ubah alamat), mangle (menandai paket), raw, address-list, dan connections.

    • Connection tracking and states
      Istilah: Connection tracking = router mencatat setiap koneksi yang lewat.

      Berkat pencatatan ini, setiap paket punya status (connection-state): new = paket pertama koneksi baru · established = bagian dari koneksi yang sudah berjalan · related = koneksi terkait koneksi lain (mis. FTP data, ICMP error) · invalid = tidak dikenal/rusak · untracked = tidak dicatat (diatur di raw). Rule umum: terima established & related, buang invalid. Lihat koneksi: /ip firewall connection print.

    • Structure, chains and actions
      Istilah: Chain = pos pemeriksaan tempat rule dikelompokkan.

      Filter punya 3 chain bawaan: input = paket menuju router itu sendiri · forward = paket yang melewati router · output = paket yang dibuat router. NAT punya chain srcnat dan dstnat. Rule dibaca dari atas ke bawah; paket berhenti di rule pertama yang cocok (untuk action accept/drop/reject). Jika tidak ada yang cocok, paket diizinkan. Urutan rule bisa digeser (drag di WinBox, move di CLI).

  • Firewall Filter in action

    Penerapan rule filter untuk melindungi router dan pengguna. Saat mengubah firewall dari jarak jauh, aktifkan Safe Mode agar tidak terkunci.

    • Filter actions

      accept = izinkan · drop = buang diam-diam · reject = tolak dan kirim balasan ICMP · log = catat ke log lalu lanjut ke rule berikutnya · jump = lompat ke chain buatan sendiri · return = kembali ke chain asal · passthrough = hanya menghitung · add-src-to-address-list / add-dst-to-address-list = masukkan IP ke address list · tarpit = menahan koneksi TCP penyerang · fasttrack-connection.

    • Protecting your router (input)

      Chain input melindungi router itu sendiri (WinBox, SSH, DNS, ping ke router). Pola dasar: izinkan established/related, buang invalid, izinkan ICMP dan akses dari LAN/admin, lalu buang sisanya (terutama dari WAN).

      /ip firewall filter
add chain=input connection-state=established,related action=accept
add chain=input connection-state=invalid action=drop
add chain=input protocol=icmp action=accept
add chain=input in-interface=ether2 action=accept
add chain=input action=drop
    • Protection your customers (forward)

      Chain forward mengatur lalu lintas client yang melewati router: izinkan established/related, buang invalid, blokir akses dari internet ke LAN kecuali yang di-port-forward, blokir situs/IP tertentu, atau batasi client tertentu.

      add chain=forward connection-state=established,related action=accept
add chain=forward connection-state=invalid action=drop
add chain=forward in-interface=ether1 connection-nat-state=!dstnat action=drop
  • Basic Address-List
    Istilah: Address list = kelompok IP dengan satu nama.

    Daripada membuat rule untuk setiap IP, kelompokkan IP dalam list (mis. ADMIN, BLOKIR) lalu pakai src-address-list/dst-address-list di rule. List bisa diisi manual atau otomatis (action add-src-to-address-list, dengan timeout).

    /ip firewall address-list add list=ADMIN address=192.168.10.10
/ip firewall filter add chain=input src-address-list=ADMIN action=accept
  • Source NAT ★ WAJIB
    Istilah: Source NAT (src-nat) = mengubah alamat pengirim paket.

    Dipakai di chain srcnat, biasanya agar PC ber-IP privat bisa ke internet memakai IP publik router.

    • Masquerade and src-nat action

      masquerade = otomatis memakai IP interface keluar; cocok untuk IP WAN dinamis (DHCP/PPPoE). src-nat = IP pengganti ditulis jelas lewat to-addresses; cocok untuk IP WAN statis dan sedikit lebih ringan.

      /ip firewall nat add chain=srcnat out-interface=ether1 action=masquerade
/ip firewall nat add chain=srcnat out-interface=ether1 action=src-nat to-addresses=203.0.113.10
  • Destination NAT
    Istilah: Destination NAT (dst-nat) = mengubah alamat/port tujuan paket; port forwarding = membuka akses dari internet ke server di LAN.

    Dipakai di chain dstnat, diproses saat paket masuk.

    • dst-nat and redirect actions

      dst-nat = teruskan ke IP/port lain (port forwarding), contoh akses IP WAN port 8080 diteruskan ke server 192.168.10.20 port 80. redirect = arahkan ke layanan di router itu sendiri, contoh memaksa semua query DNS ke DNS router, atau ke web proxy.

      /ip firewall nat add chain=dstnat in-interface=ether1 protocol=tcp dst-port=8080 \
    action=dst-nat to-addresses=192.168.10.20 to-ports=80
/ip firewall nat add chain=dstnat protocol=udp dst-port=53 action=redirect to-ports=53
  • FastTrack
    Istilah: FastTrack = "jalur tol" untuk koneksi yang sudah established.

    Paket dari koneksi yang di-FastTrack melewati sebagian besar proses firewall sehingga CPU jauh lebih ringan. Dibuat dengan rule chain=forward connection-state=established,related action=fasttrack-connection (diikuti rule accept). Kekurangannya: koneksi FastTrack melewati Simple Queue, mangle, dan IPsec, sehingga pembatasan bandwidth bisa tidak berlaku.

  • Module 6 laboratory

    Praktik: melindungi router (input), melindungi client (forward), memakai address list, membuat masquerade, port forwarding dengan dst-nat, redirect DNS, dan mengaktifkan FastTrack.

Module 7QoS
Objective
  • Simple Queue ★ WAJIB
    Istilah: QoS = Quality of Service, pengaturan bandwidth; queue = antrean untuk membatasi kecepatan.

    Simple Queue adalah cara termudah membatasi kecepatan per IP/subnet (/queue simple). Dibaca dari atas ke bawah; paket masuk ke queue pertama yang cocok.

    /queue simple add name=CLIENT-10 target=192.168.10.10/32 max-limit=2M/10M
    • Target

      IP, subnet, atau interface yang dibatasi, contoh 192.168.10.10/32 (satu PC) atau 192.168.10.0/24 (satu LAN). Arah upload/download selalu dilihat dari sisi target.

    • Destinations

      Opsional: membatasi hanya trafik target menuju tujuan tertentu (mis. hanya ke internet via interface WAN, atau ke server tertentu). Kosong = semua tujuan.

    • Max-limit and limit-at

      max-limit = batas atas kecepatan; limit-at = kecepatan minimum yang dijamin (CIR). Format upload/download: max-limit=2M/10M berarti upload 2 Mbps, download 10 Mbps. Total limit-at semua client sebaiknya tidak melebihi kapasitas link.

    • Bursting
      Istilah: Burst = izin kecepatan sesaat di atas max-limit.

      Parameter: burst-limit (kecepatan saat burst, > max-limit), burst-threshold (batas rata-rata pemakaian, di antara limit-at dan max-limit), burst-time (periode menghitung rata-rata, detik). Selama rata-rata pemakaian di bawah threshold, client boleh lari sampai burst-limit. Hasilnya: membuka web terasa cepat, download panjang tetap dibatasi.

      /queue simple add target=192.168.10.11/32 max-limit=2M/10M \
    burst-limit=4M/15M burst-threshold=1M/6M burst-time=8s/8s
  • One Simple queue for the whole network (PCQ)
    Istilah: PCQ = Per Connection Queue, membagi bandwidth rata ke banyak user secara otomatis; classifier = dasar pembeda user.

    Satu Simple Queue untuk seluruh LAN dengan queue type PCQ: setiap IP otomatis mendapat bagian yang sama, dan bagian user yang tidak aktif dibagi ke yang aktif. Classifier: download = dst-address, upload = src-address. RouterOS menyediakan pcq-download-default dan pcq-upload-default.

    /queue simple add name=LAN target=192.168.10.0/24 max-limit=20M/50M \
    queue=pcq-upload-default/pcq-download-default
    • pcq-rate configuration

      Batas kecepatan per user (per sub-stream). pcq-rate=0 (default) = tanpa batas tetap, bandwidth dibagi rata sesuai jumlah user aktif. pcq-rate=2M = setiap user maksimal 2 Mbps.

    • pcq-limit configuration

      Panjang antrean (jumlah paket) per user. Terlalu kecil = paket banyak dibuang; terlalu besar = memori terpakai dan latency naik. Ada juga pcq-total-limit untuk total semua user.

  • Module 7 laboratory

    Praktik: membatasi satu client dengan Simple Queue, mencoba limit-at dan burst, lalu membuat PCQ untuk seluruh LAN dan mengujinya dengan Torch/bandwidth test.

Module 8Tunnels
Objective
  • PPP settings
    Istilah: PPP = Point-to-Point Protocol, koneksi satu lawan satu dengan login; tunnel = paket dibungkus dalam paket lain agar bisa lewat jaringan perantara.

    PPP menjadi dasar PPPoE, PPTP, SSTP, L2TP, dan OVPN. Pengaturannya ada di menu /ppp.

    • PPP profile

      Template setting yang dipakai bersama oleh banyak user: local-address, remote-address, DNS, rate-limit (batas kecepatan), only-one (satu login per user), bridge. Profile bawaan: default dan default-encryption.

      /ppp profile add name=profile-kantor local-address=192.168.20.1 remote-address=pool-pppoe dns-server=8.8.8.8
    • PPP secret

      Akun user PPP: name (username), password, service (any/pppoe/pptp/sstp/l2tp), profile, dan opsional local/remote-address khusus untuk user itu.

      /ppp secret add name=user01 password=Rahasia123 service=pppoe profile=profile-kantor
    • PPP status

      Sesi yang sedang tersambung terlihat di PPP › Active Connections (/ppp active print): user, service, IP, uptime. Setiap sesi juga muncul sebagai interface dinamis dan rute dinamis.

  • IP pool
    Istilah: IP pool = daftar rentang IP yang boleh dibagikan.

    Dipakai oleh DHCP server, PPP, hotspot, dan VPN untuk memberi IP ke client.

    • Creating pool

      /ip pool add name=pool-pppoe ranges=192.168.20.10-192.168.20.100

    • Managing ranges

      Satu pool bisa berisi beberapa rentang (pisahkan dengan koma). Opsi next-pool = pool cadangan jika pool habis. IP yang sedang dipakai terlihat di /ip pool used print.

    • Assigning to a service

      Pool dipasang ke layanan: remote-address di PPP profile, address-pool di DHCP server, atau pool di hotspot server.

  • Secure local network
    Istilah: PPPoE = Point-to-Point Protocol over Ethernet.

    PPPoE mewajibkan login sebelum client bisa memakai jaringan, sehingga LAN lebih aman dan setiap user bisa dicatat dan dibatasi. Banyak dipakai ISP/RT-RW net. PPPoE bekerja di Layer 2: client dan server harus satu segmen Ethernet. MTU umum 1480.

    • PPPoE service-name

      Nama layanan pada PPPoE server. Client bisa memilih server tertentu berdasarkan service-name jika ada beberapa server di satu jaringan. Kosong = menerima server mana saja.

    • PPPoE client

      Router/PC yang login ke PPPoE server (mis. router kantor ke ISP). Setelah tersambung, mendapat IP dan bisa menambah default route otomatis.

      /interface pppoe-client add name=pppoe-out1 interface=ether1 user=user01 \
    password=Rahasia123 add-default-route=yes use-peer-dns=yes disabled=no
    • PPPoE server

      Router yang menerima login. Rantainya: IP Pool → PPP Profile → PPP Secret → PPPoE Server di interface LAN. Interface tersebut sebaiknya tidak diberi DHCP server agar client wajib login.

      /interface pppoe-server server add service-name=kantor interface=ether3 \
    default-profile=profile-kantor one-session-per-host=yes disabled=no
  • Point-to-point addresses

    Pada link PPP, setiap ujung punya IP: local-address = IP di sisi router/server, remote-address = IP di sisi client. Alamat ini bersifat /32 point-to-point, sehingga local-address boleh sama untuk semua client, dan router otomatis membuat rute dinamis ke setiap remote-address.

  • Secure remote networks communication
    Istilah: VPN = Virtual Private Network, tunnel aman lewat internet seolah kabel pribadi antar lokasi.

    Dipakai untuk menghubungkan kantor cabang atau karyawan yang bekerja dari luar ke jaringan kantor.

    • PPTP client and PPTP server (Quick Set)

      PPTP memakai TCP 1723 + protokol GRE. Paling mudah: centang VPN Access di Quick Set, router otomatis menjadi PPTP (dan L2TP) server dengan user vpn. Client: /interface pptp-client add connect-to=IP-SERVER user=... password=.... PPTP mudah tetapi enkripsinya lemah; jangan dipakai untuk data penting.

    • SSTP client

      SSTP membungkus PPP di dalam TLS lewat TCP port 443, sehingga aman dan bisa menembus hampir semua firewall (terlihat seperti HTTPS). Server membutuhkan sertifikat. Client: /interface sstp-client add connect-to=IP-SERVER user=... password=.... VPN modern lain: L2TP/IPsec dan WireGuard (RouterOS v7).

  • Module 8 laboratory

    Praktik: membuat IP pool, PPP profile & secret, PPPoE server dan client antar router peserta, melihat active connections, serta VPN PPTP via Quick Set dan SSTP client.

Module 9Misc
Objective
  • RouterOS tools

    Alat bawaan di menu Tools untuk uji koneksi dan otomatisasi sederhana.

    • E-mail

      Router bisa mengirim email lewat server SMTP (/tool e-mail), misalnya mengirim file backup atau notifikasi dari script/Netwatch. Isi server, port, user, dan password SMTP.

      /tool e-mail send to=admin@contoh.com subject="Backup" file=kantor.backup
    • Netwatch

      Memantau host dengan ping berkala dan menjalankan script saat host up atau down, misalnya kirim email atau pindah gateway. /tool netwatch add host=8.8.8.8 interval=30s down-script="...".

    • Ping
      Istilah: ICMP = protokol untuk pesan kontrol & ping; latency = waktu pergi-pulang (ms); packet loss = paket hilang.

      Menguji apakah host bisa dijangkau dan berapa latency-nya. /ping 8.8.8.8 count=5; bisa memilih src-address/interface. Timeout belum tentu host mati: ICMP bisa diblokir firewall.

    • Traceroute
      Istilah: Hop = satu router yang dilewati paket.

      Menampilkan daftar hop menuju tujuan beserta latency tiap hop, untuk menemukan di titik mana koneksi lambat atau putus. /tool traceroute 8.8.8.8.

    • Profiler (CPU load)

      Menampilkan proses apa yang memakan CPU (firewall, wireless, management, dns, dll.). /tool profile. Beban CPU total: /system resource print.

  • Monitoring

    Memantau trafik dan kesehatan router, baik langsung maupun dalam jangka panjang.

    • Interface traffic monitor
      Istilah: RX = data diterima interface; TX = data dikirim interface.

      Menampilkan total kecepatan RX/TX satu interface secara langsung. /interface monitor-traffic ether1, atau tab Traffic pada jendela interface di WinBox.

    • Torch

      Menampilkan trafik real-time di satu interface, dirinci per IP sumber/tujuan, protokol, dan port. Jawaban untuk pertanyaan "siapa yang sedang menyedot bandwidth?". /tool torch interface=ether2 src-address=0.0.0.0/0.

    • Graphs

      Grafik riwayat trafik interface, queue, dan resource (CPU, memori, disk) per hari/minggu/bulan/tahun. Diaktifkan di /tool graphing, lalu dilihat lewat browser: http://IP-router/graphs.

    • SNMP
      Istilah: SNMP = Simple Network Management Protocol, cara aplikasi monitoring membaca data dari perangkat (UDP 161).

      Aktifkan di /snmp agar router bisa dipantau oleh Cacti, Zabbix, PRTG, atau The Dude. Atur community dan batasi alamat yang boleh membaca; SNMPv3 lebih aman (ada autentikasi dan enkripsi).

    • The Dude

      Aplikasi monitoring jaringan gratis dari MikroTik: otomatis menemukan perangkat, menggambar peta topologi, memantau layanan (ping, HTTP, dll.), dan memberi notifikasi saat perangkat down. Terdiri dari server (paket di RouterOS) dan client (aplikasi di PC).

  • Contacting support@mikrotik.com

    Agar bantuan support cepat dan tepat, siapkan data diagnosa, log, konfigurasi yang rapi, dan diagram jaringan.

    • supout.rif, autosupout.rif and viewer
      Istilah: supout.rif = file diagnosa lengkap kondisi router.

      supout.rif dibuat manual (/system sup-output, atau tombol Make Supout.rif) lalu dilampirkan ke email support. autosupout.rif dibuat otomatis oleh router saat crash/watchdog reboot. Isinya bisa dibaca sendiri dengan Supout.rif Viewer di akun mikrotik.com. File ini memuat konfigurasi, jadi jaga kerahasiaannya.

    • System logs, enabling debug logs

      Log mencatat kejadian: login, link up/down, DHCP, error. Lihat di /log print. Aturan pencatatan ada di /system logging: pilih topik (mis. wireless, dhcp, firewall) dan tujuan (memory, disk, remote syslog). Debug log memberi detail lebih banyak (/system logging add topics=pppoe,debug); nyalakan hanya saat mencari masalah karena log jadi sangat banyak.

    • Readable configuration (item comments and names)

      Beri nama yang jelas pada interface (mis. ether1-WAN), queue, dan address list, serta comment pada rule firewall, route, dan lease. Konfigurasi jadi mudah dipahami oleh rekan kerja dan support. /interface set ether1 name=ether1-WAN; comment="blokir tamu".

    • Network diagrams

      Gambar topologi: perangkat, interface, IP/subnet, gateway, link WAN, dan server. Lampirkan saat menghubungi support dan simpan sebagai dokumentasi. Bisa dibuat dengan draw.io, Visio, atau peta The Dude.

  • Module 9 laboratory

    Praktik: ping, traceroute, Netwatch dengan script, mengirim email, memakai Torch dan Profiler, mengaktifkan Graphs dan SNMP, membuat supout.rif, membaca log, serta menamai dan memberi comment pada konfigurasi.
