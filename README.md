# Pegangan Belajar MTCNA

Rangkuman 9 modul silabus MikroTik Certified Network Associate (MTCNA) dalam bahasa Indonesia, untuk dibaca di HP atau laptop.

- `index.html`: versi web interaktif (istilah baru, ilustrasi, perintah RouterOS, jebakan ujian, kalkulator subnet, 36 soal latihan).
- `Pegangan_MTCNA.pdf`: versi PDF ukuran A5 untuk dibaca offline, lengkap dengan kunci jawaban kuis.
- `Silabus_MTCNA_Penjelasan.pdf`: urutan dan teks poin persis seperti silabus resmi MTCNA (138 poin), dengan penjelasan Bahasa Indonesia langsung di bawah setiap poin. Versi web: `silabus.html`.

Tanda di halaman: **stabilo kuning** = paling sering keluar di ujian, **★ Wajib** = bagian wajib hafal.

## Menayangkan di GitHub Pages

1. Buat repository baru di GitHub, lalu upload isi folder ini (`index.html`, `Pegangan_MTCNA.pdf`, `README.md`).
2. Buka **Settings › Pages**, pilih *Deploy from a branch*, branch `main`, folder `/ (root)`, lalu **Save**.
3. Tunggu 1–2 menit. Alamatnya: `https://<username>.github.io/<nama-repo>/`

Sumber: silabus resmi MTCNA (outline 22 Jan 2016) dan Panduan Lengkap MTCNA Bahasa Indonesia. Bahan belajar mandiri, bukan materi resmi MikroTik.
